## 狀態與來源

內建 image_gen 新生成的 raster 概念稿，並非四張原始 Approved Visual Direction Reference 的還原圖。原文件包沒有掛載四張原始二進位圖，因此依 11 與 14 已確認的文字美術方向製作：明亮手繪、Pixel Remaster、東方航海、墨綠／海藍、金框、暖紙色、紅色 CTA。

這是視覺提案，不是已完成的美術套版。沒有修改 src、交易公式、fixture、線上版本，也沒有新增航行功能。圖中 UI 文字目前為點陣圖示意；正式套用時需拆分場景、商品圖與裝飾，使用 Vue/CSS 顯示可編輯文字、價格、圖表與按鈕，不可整張壓成操作頁背景。
